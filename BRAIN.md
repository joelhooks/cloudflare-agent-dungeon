# Cloudflare Agent Dungeon Brain

This repo uses `.brain/` as the durable project graph.

- `projects/` — active outcomes, PRDs, shaping docs, plans, demos.
- `areas/` — durable systems, domain vocabulary, lifecycle rules.
- `resources/` — source-grounded research and reusable references.
- `decisions/` — rare ADR-grade decisions.
- `data/` — raw receipts and machine-readable evidence.
